# **Description du Projet**

# Ce projet consiste en la création d'un modèle d'apprentissage automatique (Machine Learning) à l'aide de l'outil Teachable Machine de Google. L'objectif est d'entraîner une intelligence artificielle à reconnaître et classifier des images en temps réel via une webcam.

# 

# **Contenu du Modèle**

# Le modèle a été entraîné pour distinguer deux classes distinctes :

# 

# **Classe "Me" (Moi)**

# 

# Échantillons : 30 images

# 

# Description : Images capturées montrant l'étudiant.

# 

# **Classe "Bottle" (Bouteille)**

# 

# Échantillons : 54 images

# 

# Description : Images d'une bouteille (marque "Holla").

# 

# Processus de Réalisation

# Collecte des données : Capture d'images via webcam pour chaque classe.

# 

# Entraînement : Utilisation de l'onglet "Training" de Teachable Machine pour générer le modèle.

# 

# Test et Validation : Utilisation de l'onglet "Preview" pour vérifier la précision du modèle en direct.

# 

# **Résultats et Observations**

# Précision : Le modèle semble capable de distinguer clairement les deux catégories.

# 

# **Test en direct :**

# 

# Lors de la présentation de la bouteille, la barre de sortie indique majoritairement "Bottle" (avec un score élevé).

# 

# Lors de la présentation de l'étudiant, la barre de sortie indique "Me".

# 

# Remarque : La capture d'écran montre une variance dans les conditions d'éclairage (une image est claire, l'autre est sombre), ce qui démontre une certaine robustesse du modèle, mais aussi l'importance de la qualité des données d'entraînement.
